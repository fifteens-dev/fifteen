15sプライバシーポリシー

15s(以下「本アプリ」)の運営者（以下「当社」）は、本アプリを利用するユーザー(以下「ユーザー」)の個人情報を保護することを重要な責務と考え、以下の通りプライバシーポリシー(以下「本ポリシー」)を定めます。

第1条(取得する情報)

本アプリは、ユーザー登録およびサービス利用の際に、以下の情報を取得する場合があります。

  1. 電話番号(SMS認証のため)
  2. 氏名、ユーザーネーム、自己紹介文、プロフィール画像などの登録情報
  3. 投稿コンテンツ(音楽・画像・コメント・Vibe設定など)
  4. 利用履歴・アクセスログ・端末情報
  5. Apple MusicまたはSpotifyアカウント連携情報(連携認証トークン等)

第2条(利用目的)

当社は、取得した個人情報を以下の目的で利用します。

  1. 本アプリの提供および運営のため
  2. ユーザー認証およびアカウント管理のため
  3. 投稿コンテンツの表示・共有機能の実現のため
  4. お問い合わせ・サポート対応のため
  5. 不正利用防止・セキュリティ強化のため
  6. 本アプリの改善・新機能開発・利用状況分析のため

第3条(第三者提供の制限)

当社は、法令に基づく場合を除き、ユーザーの同意なく個人情報を第三者に提供いたしません。

第4条(外部サービスの利用)

・Firebase Authentication / Firestore / Storage (Google LLC)

・Apple Music API (Apple Inc.)

・Spotify Web API (Spotify AB)

これらのサービスによって収集されたデータは、各社のプライバシーポリシーに従って管理されます。

第5条(個人情報の管理)

当社は、個人情報の漏洩、紛失、改ざんを防止するため、適切な安全対策を講じます。

第6条(個人情報の開示・訂正・削除)

ユーザーは、アプリ内またはサポート窓口を通じて、自身の個人情報の開示・訂正・削除を求めることができます。

第7条(未成年者の利用)

未成年ユーザーは、保護者の同意を得た上で本アプリを利用してください。

第8条(プライバシーポリシーの変更)

本ポリシーの内容は、法令その他の必要に応じて改定されることがあります。改定後の内容は、本アプリまたはウェブサイトに掲載した時点で効力を生じます。
