ノート PC からデスクトップへ。デスクトップを唯一の作業場にして、 ノート PC とスマホはそこを覗く窓にする。同期しないので、常に同一。

2026-10-16 macOS / Flutter 3.38.5 / Xcode 27 所要 2〜3 時間

このセッションの 56 コミットがノート PC にしか無かった。 b27ec95..4ff3d3d を push 済み、未 push は 0。 デスクトップはここから clone するので、以後も作業の区切りで push する。

03git に無いものを運ぶ

ここが一番つまずく。clone しただけでは動かない。 下の 6 つは .gitignore されていて GitHub に無い。

もの場所無いとどうなるか
サービスアカウント鍵 functions/fifteens-39cfe-firebase-adminsdk-....json 本番データを読む調査スクリプトが動かない
環境変数.env / functions/.envFunctions のデプロイ・ローカル実行が通らない
Firebase 設定（iOS）ios/Runner/GoogleService-Info.plistアプリが Firebase に繋がらない
Firebase 設定（Android）android/app/google-services.json同上
Claude Code の設定.claude/settings.local.json権限設定がやり直しになる
記憶 ~/.claude/projects/-Users-gotoutarou-fifteen/memory/ これまでの判断や方針が引き継がれない（10 ファイル）
運び方。秘密鍵をチャット・メール・クラウドに置かない。 同じ Apple ID なので AirDrop が手軽で確実。 暗号化ディスクイメージでも可。
Apple Music の .p8 は運ばなくてよい。 リポジトリには無く、Functions 側の秘密として既にデプロイ済み。 失効したときだけ、関数の再デプロイで足りる。

05寝かせない

エネルギー設定 手作業
システム設定 → エネルギー → 「ディスプレイがオフのときは自動でスリープさせない」を入れる。
保険
tmux の 1 ペインで走らせっぱなしにする。
caffeinate -dimsu
FileVault の判断が要る。 有効だと、停電や再起動のあと手で解錠するまで一切繋がらない。 外出先から復帰させたいなら切る。切らないなら「戻れないことがある」前提で運用する。 起業で使う前提を踏まえると、安易に切らず UPS を足して停電で落ちないようにする方が筋がよい。

06外から繋ぐ

同一 Apple ID でも「どこからでも自宅 Mac へ」は今の macOS に無い。 専用のものを入れる。

Tailscale
両 Mac とスマホを同じ tailnet に入れる。 ポート開放も固定 IP も不要で、CGNAT 配下でも繋がる。 
brew install --cask tailscale   # 両機に。同じアカウントでログイン
tailscale status                # 相手のマシン名を確認
リモートログイン 手作業
デスクトップ側。システム設定 → 一般 → 共有 → リモートログイン を入れる。
繋ぐ
# ~/.ssh/config に書いておくと楽
Host desk
  HostName <tailscale のマシン名>
  User gotoutarou

ssh desk
画面共有 必要なときだけ
Xcode・シミュレータ・Figma は GUI が要る。 システム設定 → 共有 → 画面共有 を入れ、Tailscale 越しに繋ぐ。

07運用

tmux の中で動かす — これが「つけっぱなし」の正体
Claude Code を tmux の中で動かせば、ノート PC を閉じても電車に乗っても セッションが生き続ける。接続が切れても作業は止まらない。 
ssh desk
tmux new -s 15s        # 初回
tmux attach -t 15s     # 2 回目以降（切れたら繋ぎ直すだけ）

# Ctrl-b d  … 外す（中の処理は動き続ける）
# Ctrl-b "  … 上下に分割（片方で caffeinate を走らせる）
ノート PC は窓として使う
作業ツリーはデスクトップの 1 つだけ。ノート PC からは ssh desk で同じ tmux に入る。 同期する対象が無いので、ずれようがない。
git は履歴とバックアップ
同期手段としては使わない。作業の区切りで push して、 GitHub に履歴を残す。
実機インストール 制約
端末を挿した側でしかできない。デスクトップに挿しっぱなしにするか、 配信を TestFlight に寄せる。後者なら 04 の PLA が先。

—やらないこと

iCloud Drive / Dropbox でリポジトリを同期
.git が壊れる（部分同期・競合コピー）。 build/ Pods/ node_modules/ .dart_tool/ で数十万ファイルになり同期が詰まる。
両機に独立した作業ツリーを置く
同時に触れば確実に衝突する。どうしても必要なら git のブランチ運用になるが、 その場合「リアルタイム反映」は諦めることになる。
この手順はノート PC の実際の状態（未 push・ignore されているファイル・署名の状況）を 調べて書き起こしたもの。構成が変わったらここも更新すること。
